### Objetivo da Matéria:

Introduzir os fundamentos da lógica de programação e de algoritmos, capacitando o
estudante a analisar problemas e desenvolver soluções computacionais utilizando a
linguagem **Python**. 

---

### Conteúdos:

1. Introdução a algoritmos e programação
2. Introdução ao Colab e ao Python
3. Expressões aritméticas, relacionais e lógicas
4. Comandos condicionais (`if`)
5. Comandos de repetição (`while`)
6. Comandos de repetição (`for`)
7. Tipos de dados complexos (dados não escalares)
8. Funções
9. Classes
10. Matrizes
11. VSCode, Git e GitHub
