# Programação Orientada a Objetos

**Componente Curricular:** Programação Orientada a Objetos         
**Curso:** Ciência da Computação - UFFS (Universidade Federal da Fronteira Sul)  
**Ano/Semestre:** 2025/2

---

### Professores:

- Andrei de Almeida Sampaio Braga
- Geomar André Schreiner

---

### Objetivo da Matéria:

Apresentar os fundamentos do **paradigma de programação orientada a objetos** utilizando
a linguagem **Java**, capacitando o estudante a modelar e implementar soluções baseadas
em classes e objetos. A disciplina abrange encapsulamento, herança, polimorfismo,
classes abstratas e interfaces, além de interface gráfica (Java Swing), pacotes e
persistência de dados. O objetivo é desenvolver a capacidade de projetar e construir
sistemas orientados a objetos bem estruturados.

---

### Conteúdos:

1. Paradigmas de programação
2. Introdução à linguagem Java e sintaxe básica
3. Noções de programação orientada a objetos
4. Classes e objetos (atributos e métodos)
5. Construtores, sobrecarga e métodos estáticos
6. Encapsulamento
7. Herança e especialização
8. Classes abstratas e interfaces
9. Polimorfismo
10. Interface gráfica com Java Swing
11. Pacotes e persistência de dados
